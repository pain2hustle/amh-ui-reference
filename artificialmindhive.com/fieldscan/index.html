02 — HOW IT GOES

From a blank parcel to a package you can argue about

  1. 01

    Start from a template or blank

    Pick a Fieldscape template or begin with nothing but a parcel image.

  2. 02

    Fit the concept to the land

    Calibrate the image, trace the boundary, set setbacks, drop spot elevations and runoff intent.

  3. 03

    Coordinate architecture and systems

    Plan, massing, electrical, plumbing, HVAC, solar, battery and shelter in one model.

  4. 04

    Review scope and open decisions

    Findings by discipline, with the unpriced work and unsafe assumptions named plainly.

  5. 05

    Export a discussion-ready package

    Concept JSON, blueprint set, PDF, PNG, estimate CSV, or a read-only client link.

03 — WHAT IT DOES

Built for the decisions, not the paperwork

Editable architecture

Walls, openings, levels and massing stay editable — not a rendering you have to redo.

Measured site planning

Calibrated parcel imagery, boundary, setbacks, spot elevations and runoff intent.

Systems coordination

Electrical, plumbing, HVAC, solar, battery and smart-home layers over the same plan.

Conceptual estimates

Priced lines, open lines, labor basis and exclusions, kept visibly separate.

Version history

Named revisions, restore points, comparison, and autosave recovery.

Offline-capable PWA

Install it, work with no signal, and queue changes until you reconnect.

Explicit review gates

Professional and jurisdiction decisions stay as holds. There is no “approved” badge.

04 — WHAT WE PROMISE

Nothing changes unless you change it

The assistant can read the model and propose edits, but every proposal arrives as a diff with Apply and Reject. No silent mutation, and every answer says where it came from.

  • ✓ Local-first autosaveYour project is written to your device before anything else happens.
  • ✓ Exportable project dataConcept JSON out at any time. No lock-in on your own model.
  • ✓ No hidden design changesAssistant proposals are diffs you Apply or Reject. Asking a question changes nothing.
  • ✓ Clear sources and assumptionsEvery number says whether it came from the model, a calculation, or an assumption.
  • ✓ Concept planning onlyNot survey, engineering, permit, bid, or construction documentation.
